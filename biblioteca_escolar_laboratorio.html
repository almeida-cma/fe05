🎯 O que você vai construir

Uma página HTML sobre a Biblioteca escolar, com três seções conectadas por links âncora: os passos para solicitar um livro, o catálogo de obras disponíveis em tabela, e o formulário de empréstimo que envia dados por POST.

📋 Regras fundamentais:
  • Utilize somente HTML.
  • Não utilize CSS em nenhuma forma (nem style, nem arquivo externo).
  • Não utilize JavaScript.
  • Não utilize a tag <section>.
  • Salve o arquivo com o nome exato index.html.

📐 Construção em 6 etapas

Cada etapa corresponde a uma parte do código que você vai escrever em index.html. Siga na ordem — as etapas se completam.

🏗️ Estrutura inicial do documento

Crie um arquivo index.html. Defina o idioma como pt-BR, utilize <meta charset="UTF-8"> e o título da aba como Biblioteca escolar. Dentro do <body>, use <h1> com o mesmo texto.

Antes de começar:
  • <!DOCTYPE html> avisa o navegador que é HTML5.
  • O <head> é invisível na tela; o <body> é o que aparece.
  • charset="UTF-8" garante que os acentos apareçam corretos.
  • O <title> aparece na aba do navegador; o <h1> aparece dentro da página.

🧭 Navegação com <nav>

Logo depois do <h1>, crie uma área de navegação com <nav> contendo três links <a>: Como solicitar, Catálogo e Solicitação. O separador entre eles é o caractere |.

⚠️ Cada href deve casar exatamente com um id:
  • Link Como solicitar → href="#passos"
  • Link Catálogo → href="#catalogo"
  • Link Solicitação → href="#solicitacao" (sem acento no href)

📋 Lista numerada com <ol>

Depois do <nav>, crie um <h2> com o texto Como solicitar um livro e id="passos". Em seguida, uma lista ordenada com três itens. Depois da lista, cinco parágrafos.

Textos exatos dos <li>:
  1. Consulte o catálogo de livros.
  2. Escolha o livro desejado.
  3. Preencha o formulário de solicitação.
Textos exatos dos cinco <p>:
  1. A biblioteca atende aos estudantes da escola.
  2. Consulte as informações antes de escolher um livro.
  3. Verifique o título e o autor da obra.
  4. Informe seus dados corretamente.
  5. Aguarde a confirmação da solicitação.
Detalhe importante: o id="passos" fica no <h2>, não na lista.

📊 Tabela com <table>

Depois dos parágrafos, crie um <h2> com o texto Catálogo de livros e id="catalogo". Em seguida, a tabela com border="1", uma linha de cabeçalho com três <th> e três linhas de dados com três <td> cada.

⚠️ Lembrete crítico: cada linha da tabela precisa da sua própria <tr>

O elemento <tr> (table row) é o contêiner de uma linha. A tabela do catálogo tem 4 linhas no total: 1 de cabeçalho (<th>) e 3 de dados (<td>). Cada uma delas deve estar envolvida por um par <tr>…</tr>.

Erros comuns:

  • Escrever só uma <tr> no início e achar que as próximas linhas herdam dela — não herdam. Cada linha é uma <tr> independente.
  • Esquecer o </tr> de fechamento — nesse caso o navegador tenta "adivinhar" onde a linha termina, e o resultado costuma ser desalinhamento visual ou células fora do lugar.
  • Colocar <td> fora de uma <tr> — a célula não tem linha e o navegador a descarta ou a empurra para a próxima linha, bagunçando a grade.
  • Confundir quantidade: a tabela tem 3 colunas, então cada <tr> tem exatamente 3 células. Se em uma linha você colocar 2 e na outra 4, a tabela fica torta.
Dados exatos da tabela:
LivroAutorCategoria
O Pequeno PríncipeAntoine de Saint-ExupéryFicção
Dom CasmurroMachado de AssisRomance
A Hora da EstrelaClarice LispectorLiteratura brasileira
Textos exatos dos cinco <p> após a tabela:
  1. O catálogo apresenta exemplos de obras disponíveis para consulta.
  2. A categoria ajuda a identificar o tipo de livro.
  3. Escolha uma obra de seu interesse.
  4. Confira o título antes de preencher a solicitação.
  5. A próxima etapa é informar seus dados.
Por que border="1": sem CSS, é o atributo do próprio HTML que desenha a grade. Ainda por cima, é ele que torna o desalinhamento visível — se você esquecer uma <tr>, você vê as bordas tortas e percebe o erro imediatamente.

📝 Formulário com <form>

Depois dos parágrafos, crie um <h2> com o texto Solicitação de empréstimo e id="solicitacao". Em seguida, o formulário com atributos de destino e método, os campos pareados com label e o botão de envio.

Atributos exatos do <form>:
  • action="https://httpbin.org/post"
  • method="post"
⚠️ Pares que precisam bater entre si:
  • O for do <label> Nome do estudante casa com id="estudante" no <input>.
  • O for do <label> Livro escolhido casa com id="livro" no <select>.
  • O for do <label> Prazo desejado casa com id="prazo" no <select>.
  • O name de cada campo é o nome que o dado terá quando chegar ao servidor.
Atributos exatos de cada elemento:
  • Campo Nome: <input type="text" id="estudante" name="estudante" required>
  • Select Livro: <select id="livro" name="livro"> com três <option>.
  • Select Prazo: <select id="prazo" name="prazo"> com duas <option>.
  • Button: <button type="submit"> com o texto Enviar solicitação.
  • Um par <br><br> depois de cada um dos três campos.
💡 Ponto importante sobre o atributo value em <option>

O atributo value em uma <option> não é obrigatório — a sintaxe do HTML5 permite escrever <option>Dom Casmurro</option> sem ele. Mas há uma consequência prática que você precisa conhecer:

Se você omitir value, o navegador envia o texto visível da opção. Ou seja, o formulário do nosso exemplo, sem nenhum value, enviará ao servidor algo como livro=Dom Casmurro. Isso funciona e é o comportamento esperado nesta atividade.

Se você usar value, o navegador envia o valor do atributo, não o texto. Por exemplo: <option value="dom-casmurro">Dom Casmurro</option> enviaria livro=dom-casmurro. É útil quando o valor no sistema precisa ser uma chave curta, sem espaços e sem acentos, diferente do texto exibido ao usuário.

Resumo:

SituaçãoO que é enviadoObrigatório?
<option>Dom Casmurro</option>Dom Casmurro (o texto)Não
<option value="dom-casmurro">Dom Casmurro</option>dom-casmurro (o atributo)Não — é opcional

Nesta atividade, use a forma sem value, exatamente como o enunciado pede. O atributo existe no HTML e é útil em muitas aplicações reais, mas não é exigido aqui.
