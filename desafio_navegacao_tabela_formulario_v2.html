Navegação, lista, tabela e formulário HTML — usando apenas HTML puro, sem CSS nem JavaScript

🧭 Navegação com #âncoras 📋 Lista ordenada 📊 Tabela com borda 📝 Formulário POST ✅ Validação

🎯 O que você vai construir

Uma página HTML completa sobre atividades escolares, contendo uma área de navegação com três links internos, uma lista numerada de etapas, uma tabela de atividades disponíveis e um formulário de inscrição que envia dados por POST.

📋 Regras fundamentais:
  • Utilize somente HTML.
  • Não utilize CSS em nenhuma forma (nem style, nem arquivo externo).
  • Não utilize JavaScript.
  • Não utilize a tag <section>.
  • Salve o arquivo com o nome exato index.html.

⚠️ Leia com atenção o que este mapa NÃO entrega: ele mostra apenas quais tags existem e em que ordem hierárquica. Os textos, atributos, valores e a sintaxe completa de cada parte estão descritos no enunciado (aba 2). Você vai construir linha a linha, consultando o enunciado e não um código pronto.
🚫 O que você não deve usar de forma alguma:
  • Nenhum atributo style em nenhuma tag.
  • Nenhuma tag <link rel="stylesheet">.
  • Nenhuma tag <script>.
  • Nenhuma tag <section>.

📌 Por que cada requisito existe

Requisito O que prova
<nav> com href="#id" Você sabe ligar um link ao id de um elemento da própria página — o mecanismo de âncora.
<ol> com <li> Você distingue lista ordenada (<ol>) de lista não ordenada (<ul>) e sabe que a numeração é gerada pelo navegador.
<table border="1"> Você entende a hierarquia table → tr → th/td e como o atributo border desenha a grade sem CSS.
<form method="post"> Você sabe que o formulário pode enviar dados a um destino externo e que o method altera o modo como os dados viajam.
<label for="> + <input id=""> Você entende o pareamento entre rótulo e campo — que é o que garante acessibilidade por leitor de tela e clique.

📐 Construção em 6 etapas

Cada etapa abaixo corresponde a uma parte do código que você vai escrever em index.html. Siga na ordem — as etapas se completam.

🏗️ Estrutura inicial do documento

Crie um arquivo chamado index.html. Defina o idioma como pt-BR, utilize <meta charset="UTF-8"> e o título da aba como Atividades escolares. Dentro do <body>, use <h1> com o mesmo texto.

O que você precisa saber antes de começar:
  • <!DOCTYPE html> é a primeira linha e avisa o navegador que é um documento HTML5.
  • Todo o <head> é invisível ao usuário — só o <body> aparece na tela.
  • charset="UTF-8" informa o conjunto de caracteres. Sem ele, acentos aparecem errados.
  • O <title> aparece na aba do navegador, não na página.

Não confunda: o título da aba (dentro do <title>, no <head>) é diferente do cabeçalho da página (dentro do <h1>, no <body>). Nesta etapa, ambos têm o mesmo texto.

🧭 Navegação com <nav>

Logo depois do <h1>, crie uma área de navegação com <nav> contendo três links com <a>. Os links são: Etapas, Atividades e Inscrição. O separador entre eles é o caractere |.

⚠️ Ponto crítico de atenção: cada href deve corresponder ao id que você vai criar nas próximas etapas. O enunciado define:
  • Link Etapas → href="#etapas"
  • Link Atividades → href="#atividades"
  • Link Inscrição → href="#inscricao" (sem acento no href)
Se o href e o id não baterem exatamente, o link não funciona.

📋 Lista numerada com <ol>

Depois do <nav>, crie um <h2> com o texto Como participar e id="etapas". Em seguida, uma lista ordenada com três itens. Depois da lista, cinco parágrafos.

Textos exatos — copie daqui:

Os três <li> na ordem:

  1. Escolha uma atividade.
  2. Preencha o formulário.
  3. Envie sua inscrição.

Os cinco <p> na ordem:

  1. Leia as orientações antes de continuar.
  2. As atividades são destinadas aos estudantes da escola.
  3. Consulte os horários e escolha a opção desejada.
  4. Organize seus dados antes de preencher a inscrição.
  5. Confira todas as informações antes de enviar.
Detalhe que não deve passar despercebido: o id="etapas" fica no <h2>, não na lista <ol>. Isso é o que faz o link "Etapas" rolar até o título.

📊 Tabela com <table>

Depois dos cinco parágrafos, crie um <h2> com o texto Atividades disponíveis e id="atividades". Em seguida, a tabela com border="1", uma linha de cabeçalho com dois <th>, e duas linhas de dados com dois <td> cada.

Dados exatos da tabela:
Atividade Turno
Desenvolvimento WebManhã
RobóticaTarde
Textos exatos dos cinco <p> depois da tabela, na ordem:
  1. Desenvolvimento Web permite conhecer a criação de páginas.
  2. Robótica explora a construção e a programação de projetos.
  3. Escolha a atividade de acordo com seu interesse.
  4. Depois, vá até a seção de inscrição.
  5. Preencha os campos com atenção.
Por que border="1": sem CSS, é o único jeito de o navegador desenhar linhas visíveis na tabela. O atributo é considerado obsoleto em HTML5 moderno — normalmente usaríamos CSS — mas nesta atividade ele é intencional para você ver a grade sem nenhum estilo.

📝 Formulário com <form>

Depois dos parágrafos da etapa 4, crie um <h2> com o texto Inscrição e id="inscricao". Em seguida, o formulário com os atributos de destino e método, dois campos pareados com label e o botão de envio.

Atributos exatos do <form>:
  • action="https://httpbin.org/post"
  • method="post"
⚠️ Três pares de atributos que precisam bater entre si:
  • O for do primeiro <label> casa com o id do <input> — ambos devem ser nome.
  • O for do segundo <label> casa com o id do <select> — ambos devem ser atividade.
  • O name de cada campo é o nome que o dado terá quando chegar ao servidor. Não confunda com o id, que serve para o for do label.
Atributos exatos de cada elemento do formulário:
  • Campo <input> — type="text", id="nome", name="nome", required.
  • <select> — id="atividade", name="atividade".
  • As duas <option> — textos "Desenvolvimento Web" e "Robótica", nesta ordem.
  • O <button> — type="submit" e texto "Enviar inscrição".
  • <br><br> — um par depois do campo Nome, outro depois do <select>.

🧪 Teste obrigatório

Abra index.html no navegador e execute os testes da aba 5 deste material. Se todos passarem, sua página cumpre os requisitos.

Resumo do que você precisa testar:

  • Clique em Etapas → a página deve rolar até o <h2> "Como participar".
  • Clique em Atividades → rola até "Atividades disponíveis".
  • Clique em Inscrição → rola até o formulário.
  • Preencha o nome, escolha a atividade e clique em Enviar inscrição.
  • Observe a resposta do serviço externo (se houver internet).
⚠️ Aviso importante: o httpbin.org é um serviço de testes. Ele não faz inscrição real, não guarda dados e não envia e-mail. Use somente dados fictícios (como "Ana" e "teste@exemplo.com") para não expor informação pessoal real na web.

🧪 Testes obrigatórios

Depois de montar o index.html, execute os testes abaixo na ordem. Eles provam que a página funciona de fato.

1
Teste de navegação — Etapas

Clique em Etapas na barra de navegação. A página deve rolar até o título "Como participar". Observe que a URL ganha #etapas no final.

2
Teste de navegação — Atividades

Clique em Atividades. A página deve rolar até o título "Atividades disponíveis".

3
Teste de navegação — Inscrição

Clique em Inscrição. A página deve rolar até o título "Inscrição" e mostrar o formulário.

4
Teste do formulário

Preencha o nome, escolha uma atividade no <select> e clique em Enviar inscrição. Sem internet, o navegador mostrará um erro de destino — isso é esperado e prova que o formulário tentou enviar.

5
Teste com internet — observação do httpbin

Se houver conexão, você verá uma página em branco com um texto no formato JSON. Nele aparecerá "form": {"nome": "...", "atividade": "..."}. Isso prova que os dados chegaram ao destino e foram recebidos pelo serviço.

⚠️ Lembrete: o httpbin.org é um serviço de testes públicos e abertos. Nunca digite dados reais (nome completo verdadeiro, e-mail pessoal, senha). Use sempre dados fictícios como "Ana", "João", "teste@exemplo.com".
